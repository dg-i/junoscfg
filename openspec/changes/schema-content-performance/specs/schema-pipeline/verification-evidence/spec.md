## ADDED Requirements

### Requirement: Pure schema checks retain content-bound proof
WHEN qualification generates exact checker input bytes THEN the adapter SHALL execute
Draft202012Validator.check_schema and Lark(start="start") or verify successful template-owned
proof bound to the same input, worker, runtime and dependency implementation; completion
SHALL record executed or reused lineage and bind it to the parent evidence.
Tests: `tests/tooling/test_schema_verification.py::TestCandidateIntegrity::test_real_runner_exports_artifacts_without_mutation`

#### Scenario: Unchanged input after a repository edit
- **WHEN** fresh generated bytes and checker identity match complete valid proof
- **THEN** the pure operation is reported as reused and all other required work executes

#### Scenario: Invalid proof or changed inputs
- **WHEN** proof is missing, corrupt, incomplete or bound to different inputs or implementation
- **THEN** the actual checker executes and failure cannot fall back to old success
