## Why

The schema tier generates real artifacts but exposes no executed completion manifest or immutable per-dump evidence contract. The qualified inactive template now supports those contracts; this adapter makes schema verification truthful and reusable after a separately reviewed activation.

## What Changes

- Add one thin application adapter, three physical dump shards, exact executed pytest reports, generated byte-stability and one uncached shipped-release sentinel.
- Bind ignored XSD bytes and observed versions through existing expensive-tier fields; refuse incomplete inputs, outcomes and mutations before reporting success.
- Run actual scaffold and caps homes; add inactive verification and ignored evidence seeds, exact template-owned skill report-only patterns and two delivered-guide navigation links.
- Search `SCHEMA_DIR`, `schema_data`, `JUNOSCFG_XSD_SOURCE`, `ARTIFACT_DIR`, `real_artifacts`, `build_from_xsd` and `__file__`: existing readers are tests/support/schema_data.py, tests/support/regen.py, tests/conftest.py and tests/corpus/test_schema_data.py; schema commands use ArtifactBuilder. Adapter shard selection uses the existing fixture without changing those readers or adding environment overrides.

## Capabilities

### New Capabilities

- `schema-pipeline/verification-evidence`: actual schema completion, physical input identity and candidate-preserving generated proof.

### Modified Capabilities

None; existing schema/product requirements and assertions remain.

## Non-goals

Activation, legacy import, product semantics, generator fixes, changing count assertions, a second cache, stage/surface/hook/cap-budget changes, publication and measured efficiency claims.

## Impact

Application tools, tooling tests, exact manifests, pyproject.toml, .gitignore, mkdocs.yml and the batch guide; no runtime dependency or consumer/CLI change. Standard feature lane, independent Test/Challenge and fresh Reviewer. Removes no product capability; executable reporting replaces manual reporting. Efficiency remains UNMEASURED.
