The adapter adds truthful reporting and physical/version preflight, not another schema pipeline or cache.

## Decisions

- A single tools/schema_verification.py owns command orchestration and a pytest plugin; tools/schema_verification.CONTRACT.md states truthful completion and no-mutation invariants. Tests use public tool functions and real small pytest sessions. Production always runs the existing fixed schema suite.
- Three declarations bind one physical dump each. Required JSON manifests name exact 12 node IDs and one shard. The plugin selects callspec schema_dump, asserts selected collection equals obligations, and records actual setup/call/teardown reports. Passed calls or exact reviewed release skips complete an ID only with successful setup/teardown; result and truthful outcome records are distinct.
- An immutable prepared ignored runtime JSON names observed Python/pytest/lxml/libxml2/jsonschema/Lark versions. Execution verifies these observations rather than rewriting them. Missing/unknown/mismatched inputs refuse before expensive work. Validate declared dump and every parent component against symlinks; reject staging new.xsd before existing discovery could rename it.
- Per-shard stable outputs come from the actual real_artifacts fixture, preserving generated bytes. Metadata alone has the established generated_at exception; all other metadata fields agree. For shipped release, protected outputs must equal the committed artifact set. Commands snapshot qualified tracked candidate and explicit read-input bytes before/after and remove success output on failure or mutation. Dirty admission and snapshots share the installed public verification.EVIDENCE_RECORDS predicate for only exact openspec/changes/<slug>/<record> paths; policy, suite, runtime, dump, required and stability inputs override record spelling. Source, tasks, configuration, nested/archive paths and other tracked inputs remain protected.
- Sentinel runs public ArtifactBuilder.build into a fresh temporary directory from the shipped dump, validates versions first and compares committed products. It has no cache path and does not overwrite stable tier evidence. Template stability executes the actual suite twice; four raw gzip products are its stable manifest. Existing mtime=0 supports meaningful raw comparison.
- Result/runtime/outcome/artifact paths are ignored under .agent-ready/schema/. The template's result JSON remains exactly tests/shards; detailed observed reports retain skips and reasons separately. Version input also appears in shipped tier inputs because the sentinel inherits inputs only.
- Actual scaffold/homes and the exact inactive/application-ownership seed changes are phase-5 tasks. Generic preview recommendations do not redefine application policy. Document navigation links expose the delivered lifecycle and verification guides.
- Root owns later activation, integration/archive/version/tag and migration. No product implementation until STOP-T independent challenge; exact immutable full plus real schema evidence precede STOP-R and fresh review.

## Risks

- Suite additions/removals intentionally fail exact manifests until obligations are updated and reviewed; copied collection IDs cannot conceal missing execution.
- A count skip may originate in call phase; only existing explicitly reviewed IDs/reasons are permitted, with successful setup/teardown, and evidence retains skipped status. All-skipped runs fail.
- Legacy symlink inputs refuse even when readable. Physical private inputs must be provisioned, never published. New/unknown dump inventories cannot silently mutate discovery inputs or weaken coverage.
- Source/config/test/runtime/lock/input mutation invalidates evidence; fail closed and preserve failed logs rather than refresh snapshots during execution.
- The sentinel and two genuine stability passes have real costs. Capture observations and keep efficiency UNMEASURED; no claim follows from synthetic tests.

Approved design derives the owner's bounded instruction and existing contracts; no unresolved material choice or new dependency exists. Resume phase 4 red acceptance, then STOP-T.
