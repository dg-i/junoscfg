# Observe OpenSpec artifact readership

Application-owned cohort settings for the shared
[artifact-readership protocol](observe-artifact-readership.md).

## Observe OpenSpec artifact readership for one release

For the [simplification roadmap](../roadmaps/2026-10-08-junoscfg-simplification.md),
the baseline is `v0.14.0`; observation does not begin until that tag exists,
and it closes at the next release tag on the target branch. Record both tags'
immutable commits as the shared protocol requires.

Both tagged trees must have no live OpenSpec change directories. This local
cohort permits no straddling-change exception. Keep cohort choices, participant
observations and the coverage audit with the change metrics and observation
report. Apply the shared protocol's recording, completeness, consumer checks
and separate-proposal requirements before considering any artifact deletion.
