# Solo review

Set `solo = true` beside the stage owners when one maintainer owns this
repository. The policy is owner acceptance plus fresh agent review:
fresh agent review is a second read, not a second human.

Have a fresh agent session examine the diff, specifications and tests. Resolve
its findings and record the owner's acceptance in the change. This does not
claim independent human review or count as hosting-platform self-approval.

Document the solo exception to any red-zone human-pair policy. Configure the
host so mandatory independent approval does not make solo work impossible,
and record the exception and its risk. The template cannot verify remote
settings. Revisit the policy when another maintainer joins.
