Set and structured input that quote a policy name starting with `(` (`import "( P-A && P-B )"`) now keep its quotes in the IR, as the device's XML and JSON do (`"import": ["\"( P-A && P-B )\""]`); it used to read as an expression over two policies, another configuration. JSON and YAML output of such input change: regenerate JSON or YAML written from it, and strip one pair of quotes where a tool compares such a value with a policy name. `junoscfg audit` writes a definition name as any value: one that looks like an expression (`( A && B )`) is quoted, and an inner `"` is escaped; a tool that matches audit output against a name strips the quotes and unescapes `\"`.
