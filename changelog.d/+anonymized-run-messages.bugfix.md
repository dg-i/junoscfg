`anonymize()` no longer rewrites the IR its caller passes: it copies it once and returns the anonymized copy as `AnonymizeResult.ir`, as the README always showed. A caller who read the anonymized values from its own dict reads `result.ir`. `apply_revert` and `walk` still rewrite the IR they are given, as documented. The `anonymize:` warning reads "each address ... in it is replaced". The AS-number rule's warnings name no AS number, and `--anonymize-log-level debug` is documented as printing each original beside its replacement.
