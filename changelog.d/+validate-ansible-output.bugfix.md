Set and structured validation no longer reject configuration the `dgi/junos-config` Ansible collection renders. Three causes: `set groups <name> ...` was rejected because `groups` is the one container of 135 whose transparent child carries no `nokeyword` flag; `apply-flags` and `apply-macro` were not stripped before parsing, though neither is in the schema; and a quoted ssh key could not be a list entry name, since list rules took `/\S+/`.
