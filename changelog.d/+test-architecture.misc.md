Validation compiles the set grammar and loads the JSON/YAML schemas once per process while the files are unchanged, where every `validate_*` call rebuilt them; the test suite went from 186 s to under a minute. The suite is laid out by layer (`tests/unit/<package>/`, `tests/contract/`, `tests/corpus/`), measures branch coverage against a floor that only rises, and runs the tests a commit affects from pre-commit. The package doors export the names their stages return and compose: `junoscfg.convert` adds `FieldError`, `FieldValidationResult` and `UNPLACED`; `junoscfg.validate` the schema pipeline's stages and the format validators; `junoscfg.anonymize` the rule classes, `Rule`, `build_rules`, `PathFilter` and `walk`; `junoscfg.audit` `STYLE_CHOICES`, `TypeEntry`, `collect_occurrences` and `render`; `junoscfg.edityaml` gains an `__all__`.
