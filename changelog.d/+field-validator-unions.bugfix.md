Field validation no longer warns on values the Junos XSD permits. A `nokeyword` leaf's enum is now advisory, because the XSD models those as a union of an enum with a freeform type and only the enum survives extraction — `classifier-name` carries `['default']` yet takes any classifier name. And `ipaddr-or-interface` accepts an interface name as well as an address. Measured over Juniper's own Validated Designs corpus, 1,535 configurations and 4.9M lines, this takes field warnings from 53,326 to 217, of which 199 name a template `$VARIABLE`.
