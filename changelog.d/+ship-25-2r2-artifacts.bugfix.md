The bundled schema artifacts are regenerated from a Junos 25.2R2 dump. The 24.4R0 set was missing statements every other release carries, among them `firewall family inet6 filter term from hop-limit` and `forwarding-options analyzer`; across three real device configurations that was 20 of 21 rejected set lines, and every `hop-limit` converted to a fused key. The set grammar now models `apply-groups`, `apply-groups-except`, `apply-flags` and `apply-macro` itself, so the validator no longer cuts them off the line; the one-line bracket form `apply-groups [ a b ]` is rejected like every other bracket list. `JUNOSCFG_ARTIFACTS` and `--artifacts` still select another set.
