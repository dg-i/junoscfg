Rebuilt the bundled `junos-set.lark`, so `junoscfg -v` validates set and structured input again instead of reporting "Error loading validation artifacts" on every configuration. The grammar is rebuilt from the bundled structure tree via the new `read_structure_tree`, because the Junos 24.4R0 dump it came from is not in the repository. Validation is structural and still rejects some valid configuration — notably more than one setting after a list entry name on one line, which is what keeps a 5,000-line configuration at about 18 seconds rather than 19 minutes; see the validation guide.
