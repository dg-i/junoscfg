Fixed three Lark grammar generator defects that made a generated grammar reject most valid configuration: named lists merged with same-named containers and lost their entry-name slot, nokeyword containers emitted a keyword that set commands never write, and a container could not be set bare. On the bundled 24.4R0 schema a rebuilt grammar now accepts 99 of this repository's 113 distinct set commands, up from 23. The grammar shipped in this package is unchanged and still does not load.
