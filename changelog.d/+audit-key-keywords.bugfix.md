The unused-object audit's occurrence paths (`collect_occurrences`, and the verbose `# unresolved:` lines built from them) now write a keyed entry's key as the set writer does: a key field the device writes with its keyword keeps it (`virtual-link neighbor-id 10.0.0.1 transit-area 0.0.0.2`), and a route filter's match type keeps its value (`upto /24`, `prefix-length-range /16-/24`). The delete, deactivate and show command lines are unchanged.
