JSON and YAML output no longer invents an `enable-disable` statement. `protocols { ospf { disable; } }` converted to `{"enable-disable": "disable"}`, where a device renders `{"disable": [null]}` and Junos has no `enable-disable` statement at all. The schema folds the on/off switch into one node whose name joins both spellings, and the converter keyed on the node rather than the token.
