Anonymization reaches every value the schema places. `apply-groups`, `apply-groups-except` and `apply-macro` below the top level, `interface-range` and the other children of `interfaces` beside `interface`, and a list a container holds (the port-mirroring `routing-instance` in JSON) used to pass every rule unchanged. A group and every reference to it now get one name whichever rules are on; with the group and sensitive-word rules together the top-level `apply-groups` used to name no group, and revert failed. Groups named `re0`, `re1`, `node0`, `node1`, `member<N>` or a `$` variable such as `${node}` keep their names. The IP rule replaces an address on a leaf typed `host`, `hostname` or `ipprefix-only` (`system tacplus-server`, `radius-server`, `snmp trap-group targets`, NAT `source-prefix`) and on a leaf with no type (an `apply-macro` value), and it no longer crashes on an interface name where an address may stand (`from interface ge-0/0/0.0`, `next-hop ge-0/0/0.0`) or on text beside an address (`203.0.114.9/rack-4`). An SNMP OID and a `from area` stay as written.
