Junos tags (`inactive:`, `protect:`, `replace:`, `delete:`) now mark the node the device marks. Structured input gives a tag to the node its statement starts: `inactive: route 0.0.0.0/0 next-hop 10.0.0.1;` deactivates the route, where it deactivated `next-hop`. Structured output writes a tag at the head of its line (`inactive: family inet {`, not `family inactive: inet {`) and never joins a tagged statement onto its parent's line. A tag on `family` itself, which the device rejects, is reported as a statement that cannot be placed; structured output drops it with a note. XML input keeps `protect="protect"`. The internal `replace <path>` set pseudo command and `SetConverter(emit_replace=…)` are removed.
